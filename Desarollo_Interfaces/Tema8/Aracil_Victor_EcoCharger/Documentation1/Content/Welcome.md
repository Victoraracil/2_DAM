# Documentación de EcoCharger

Bienvenido a la documentación oficial de **EcoCharger**, una aplicación diseñada para gestionar infraestructuras de carga de vehículos eléctricos de forma eficiente y segura.

EcoCharger proporciona herramientas para administrar los principales componentes de un ecosistema de carga, incluyendo usuarios, estaciones de carga, cargadores, tarifas y sesiones de carga.

Esta documentación ha sido generada mediante **Sandcastle Help File Builder** y contiene información detallada sobre los servicios y métodos disponibles en el proyecto.

---

## Descripción del Proyecto

El sistema EcoCharger ha sido desarrollado para facilitar la administración de entornos de carga para vehículos eléctricos.  
Permite a desarrolladores y administradores realizar operaciones esenciales como:

- Gestionar los usuarios registrados
- Controlar las estaciones de carga y sus cargadores
- Configurar las tarifas energéticas
- Supervisar las sesiones de carga
- Mantener la relación entre las diferentes entidades del sistema

Cada clase de servicio se encuentra completamente documentada, describiendo su funcionalidad, parámetros, valores de retorno y ejemplos de uso.
